# Requirements Interview

Map decisions and prerequisites. Ask currently answerable questions in numbered rounds,
give recommendations/trade-offs, then wait. Defer dependent questions until prerequisites
are settled. Look up available environment facts; ask users for decisions, not facts
already observable in the repository.

Test normal, failure, and security scenarios. Clarify write effects, acceptance evidence,
runtime assumptions, production approval, and rollback. Identify unresolved choices
instead of silently selecting sensitive policies. Avoid repeating settled questions.

Summarize shared understanding and obtain confirmation before implementation. Follow
root agent rules; interviews do not authorize production access.
