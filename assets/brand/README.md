# EnergyDrive Brand Assets

![EnergyDrive logo](energydrive-logo.png)

## Included Asset

`energydrive-logo.png` is the original 210 x 60 PNG recovered from the supplied
RappCloud project archive. It is copied without recoloring, cropping, or resampling.

Provenance: archived member `rappCloudTest/static/EDS-Logo.png`. The archived
`api/savings_report_routes.py` uses this asset through ReportLab's ImageReader for
PDF reports; the project's web pages use the same logo. The source ZIP is a review
input, not a required dependency or template deliverable.

## Reuse

- Use in EnergyDrive project interfaces, report headers, documentation, and slides.
- Preserve the aspect ratio and original colors; provide space around the artwork.
- The supplied image has a white background. Prefer a compatible light background;
  do not assume it is a transparent or dark-background variant.
- At 210 x 60 pixels, it is not a high-resolution print master. Avoid stretching it
  across large slides or print layouts. Obtain an approved SVG or larger original
  from the brand owner for those uses; do not recreate the wordmark or invent variants.
- Projects may copy it into their framework's static assets, PDF asset directory,
  or Ignition image resources. This template does not import it into a live gateway.

These are practical reuse notes, not a complete official brand manual or a public
redistribution license. Confirm any external use or altered variant with the brand owner.
