# Glossary

| Term | Meaning |
| --- | --- |
| Starter template | Reusable starting point for a new project, not a deployed application. |
| Profile | Rules applicable to a selected technology or workload. |
| Production write | An action changing live organizational data or infrastructure. |
| Control write | An action that can cause equipment behavior, directly or indirectly. |
| Release approval | Authorization by the designated person to promote a reviewed release. |
| Operational approval | Authorization by the responsible operator for an equipment-affecting change. |
| Release artifact | An immutable, identifiable deliverable promoted between environments. |
